# Northwind Group consolidation

Bundle ID: NWG-D0BC

Consolidates Northwind Inc. (US, parent), Northwind UK Ltd (100%) and Northwind
India Pvt Ltd (80%, acquired 1 July 2024) into group financial statements in
GBP for the year ended 31 December 2024, from the trial balances and manual
journals in `data/`.

## Setup

Python 3.11+. No external dependencies for the pipeline itself; pytest is only
needed to run the test suite.

```
python3 -m venv .venv
. .venv/bin/activate
pip install pytest
```

## Run

```
. .venv/bin/activate
PYTHONPATH=src python -m northwind.main
```

This reads everything from `data/` and writes to `output/`:

- `consolidated_tb.csv` - every group account's balance with the source rows behind it
- `balance_sheet.json`, `profit_and_loss.json`, `changes_in_equity.json`
- `eliminations.csv` - every elimination entry with the source rows it eliminates
- `issues.json` - every problem found in the data, what it affects, what the pipeline did about it
- `control_figures_mk.json` - the 12 appendix figures

Pass `--initials xx` to change the control figures filename, or `--data-dir` /
`--output-dir` to point at different locations. The brief's `/output` is this
repo's `output/` directory - there's nothing that writes to filesystem root.

## Tests

```
. .venv/bin/activate
python -m pytest
```

29 tests: one file per pipeline module, plus `test_consolidate.py` for the
end-to-end identities (net assets reconciles to group profit plus opening
equity plus NCI; the balance sheet balances) and the known data problems
(JE-006's embedded instruction to skip its own balance check, the duplicate
audit-fee journals, the India GST account with no mapping, the out-of-period
journal, the UK sub-ledger mismatches, the wrong map_uk.csv mapping).

## Layout

```
src/northwind/
  io_loaders.py        read each entity's TB in its own export format
  mapping.py            apply map_uk.csv / map_in.csv, catch wrong mappings
  adjustments.py        validate and post/reject/hold the 20 manual journals
  fx.py                 rate lookups and cross-rate derivation
  acquisition.py         goodwill/NCI at acquisition, India's pre/post-acq P&L split
  intercompany.py        item-in-transit, remeasurement, elimination
  subledger_checks.py     tie AR/AP control totals to the GL
  translation.py          local currency -> GBP at a given rate type
  consolidate.py           orchestrates all of the above into one result
  statements.py            builds the output JSON/CSV shapes
  validate.py              runtime identity checks
  control_figures.py        the 12 appendix figures
  main.py                   CLI entry point
tests/                      one file per module above, plus test_consolidate.py
data/                        the assignment's input bundle, unmodified
output/                      generated by running the pipeline
```

See `ARCHITECTURE.md` for the design, `DECISIONS.md` for the judgment calls,
`VALIDATION.md` for how the output is checked, and `REFLECTION.md` for what
I'd do differently with more time.
